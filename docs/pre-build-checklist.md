## Archived 2026-10-17

This checklist was written on 2026-06-28, before the Godot project existed, as
a punch list for reaching the first playable. It was overtaken within weeks and
is no longer maintained: the game builds, CI runs on every change, and a
`v0.1.0` pre-release has been published (see
[v0.1.0 release notes](release-notes/v0.1.0.md)). Do not read its task list as
the state of the project. The living punch list is
[`plan/week.json`](plan/week.json), the machine-readable plan for the current
week, where every open item carries its files and acceptance criteria. Each
week it is written alongside a build review in
[`obsidian-vault/build-reviews/`](../obsidian-vault/build-reviews/README.md)
that says what is open and why. Phase scope and exit criteria stay in the
[roadmap](roadmap.md), and the original text of this file is in git history at
commit `d37f114`.
