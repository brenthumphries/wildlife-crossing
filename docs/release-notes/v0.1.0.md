## Highlights

The first public build of Wildlife Crossing. It is a small, honest slice: one
real place, the Bow Valley in the Central Canadian Rockies, where a highway
cuts a wildlife corridor in two. You can survey the land, build a crossing
over the highway, and watch animals find it. It is early, and the parts that
are not finished are listed below rather than hidden.

## Scope of this release

Four things about this build are deliberate. None of them is a bug.

- **Bow Valley only.** Bow Valley (Central Canadian Rockies) is the only
  playable area. The other eleven regions of the Yellowstone to Yukon corridor
  are authored and appear on the world map, but they are locked, because the
  system that unlocks them is not built yet.
- **The world map is look-only.** The world-map screen (`M`) shows the regions
  and their lock state, but you cannot click a segment on it. You place
  crossings from the Bow Valley tutorial with `B`. Phase 2's exit criteria are
  met in tests; selecting a segment from the world map is not reachable in this
  build.
- **Placeholder art and the default icon.** Most sprites, the crossing cue and
  its chime are stand-ins, and the app uses Godot's default icon. Only the Bow
  Valley card on the world map has real art.
- **Some builds are signed and some are not.** The Mac build is signed and
  notarized by Apple. The Windows build is unsigned. Checksums for every file
  are signed with GPG. See [Downloads and verification](#downloads-and-verification).

## What's new

- A playable Bow Valley tutorial sub-area on a hex map, with terrain, roads,
  habitat patches and eight species from the corridor.
- Crossings you can build over a road segment: a fully spanned overpass gives
  animals a safe route, a partial span does not.
- A connectivity overlay that shows how well habitat patches are joined,
  shaded from orange (poorly connected) to teal (well connected).
- A HUD message line and a "+N crossed safely" flash and chime when animals
  use a crossing.
- Population change that responds to connectivity, so a patch that is too
  small on its own can recover once a crossing joins it to a bigger network.
- Quick save (`F5`) and quick load (`F9`), and a Credits and Licences screen
  (`F1`) listing every third-party component.
- Two small minigames, reachable with `F2` and `F3`.
- Downloads for Mac, Windows and Linux, with signed checksums.

## Known issues

- **Windows shows a warning.** The Windows build is unsigned on purpose. Windows
  will probably show "Windows protected your PC" with an unknown publisher.
  Choose *More info*, then *Run anyway*. Some antivirus programs flag unsigned
  Godot games by mistake. The checksum steps below are how you confirm the
  files are the ones we published.
- **The world map cannot select segments.** See the scope above. Use `B` to
  build.
- **Eleven regions are locked** and cannot be entered.
- **Two Phase 1 features are not in this build:** species-preference weighting
  of crossings, and the crossing usage counter.
- **No pause menu.** Save, load, credits and the minigames are keyboard
  shortcuts until a menu exists.

## Downloads and verification

Every release file is on the GitHub Releases page.

| File | Platform | Signed |
|------|----------|--------|
| `wildlife-crossing.dmg` | macOS | Yes: Apple Developer ID, notarized and stapled |
| `wildlife-crossing.exe` with `wildlife-crossing.pck` | Windows | No |
| `wildlife-crossing.x86_64` with `wildlife-crossing.pck` | Linux | No |
| `SHA256SUMS.txt` and `SHA256SUMS.txt.asc` | All | Manifest signed with GPG |

Keep the `.pck` beside the Windows or Linux binary. On Linux, run
`chmod +x wildlife-crossing.x86_64` first.

To check your download, import the public key
[`wildlife-crossing-signing-key.asc`](../../wildlife-crossing-signing-key.asc),
confirm its fingerprint reads:

```
7F68 A7E0 6349 DA13 6226 F04E 2D5F 1ED6 EFFC 08FD
```

then, in the folder holding your download and the two `SHA256SUMS` files, run:

```
gpg --verify SHA256SUMS.txt.asc SHA256SUMS.txt
```

```
shasum -a 256 -c SHA256SUMS.txt
```

The first proves the checksum list was signed by that key. The second proves
your files match the list. Files you did not download will be reported as
missing, which is expected. A GPG signature proves integrity and origin. It does
not stop macOS or Windows from showing a warning of their own.
