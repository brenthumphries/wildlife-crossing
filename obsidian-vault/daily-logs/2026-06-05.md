## What I worked on

Wrote two PRDs: the crossing location selection interface (the macro-level map
step that precedes specific crossing construction) and the game design overview
(the anchor document describing the full game, its systems, and how they
interact).

## What got done

- Created `obsidian-vault/prd/crossing-location-selection.md` — PRDs the
  UI where the player selects a general crossing site on the map before entering
  the construction workflow. Scoped to minimal v1: toolbar-triggered, connectivity
  overlay, hover highlight, confirmation panel with budget display.
- Created `obsidian-vault/prd/game-design-overview.md` — the master design
  reference for the game. Covers vision, the four design pillars, the core
  gameplay loop, and all planned systems: habitat, species, crossings, economy,
  information purchases, seasons, and player progression. Includes a system
  interaction table and six open questions.

## Decisions made

- **Crossing location selection is a distinct step from construction.** The
  player commits to a general location first, then enters the specific
  tile-placement workflow. This keeps the two concerns separate and allows each
  to be designed and built independently.
- **Segment definition is unresolved for v1.** Whether a "segment" for location
  selection means a single tile, a logical road section, or a player-drawn zone
  is an open question that must be resolved before implementation begins.
- **Game design overview lives in `prd/`** alongside feature PRDs rather than
  in `design/`, so it's easy to find and link to from other PRDs.
- **Core loop is: survey → select → build → observe → earn → unlock.** Donations
  are the primary income mechanism; effective crossings generate donations;
  progression unlocks new land through demonstrated ecological impact.

## Open questions / blockers

- How should First Nations communities be portrayed in the progression system?
  Consider external cultural consultation before this system is designed in

- Is there a campaign win condition or is this a sandbox? (Owner: product owner.)
- How is time paced — how long is a season, can the player speed up or pause?
  (Owner: design.)
