- **Hint seen but never shown.** On the first run the donation arrived, "Last donation" appeared, and no hint banner did, with no other banner on screen. `settings.cfg` afterwards listed `first_donation` as seen. Removed it from the list and re-ran with a temporary debug line (reverted, not committed): the banner showed, and the coach reported no current hint before the event and `first_donation` after it. Cause of the first miss is **not found**; the code and `hint_coach_test.gd` look correct. One thing worth hardening regardless: the coach marks a hint seen when it is queued, not when it is shown, so a miss like this is lost for good.
- **Cue timing at 4x.** At 4x the "+N crossed safely" cue came less often and with larger numbers (the terminal showed "+427" and "+129"). The cause is in `game/scripts/main.gd`: the coalescing window `CROSSING_FEEDBACK_COALESCE_SECONDS` (2.0, `simulation_constants.gd`) is counted in real seconds (frame delta), so at 4x one window holds about four times the crossings. Read from the code, not yet changed.
- **No sound on donation.** No cue played at the donation. The code plays a sound only for milestones (`_milestone_player`); the donation handler sets the label and shows the hint and nothing else. Not a bug, but a gap if a donation cue was intended.
- **Settings restore.** The original `settings.cfg` is at `settings.cfg.bak` in `~/Library/Application Support/Godot/app_userdata/Wildlife Crossing/`; restore it after the walk.

## Decisions made

- **No donation sound for now.** Possibly later as a player-configurable option. Not filed as an item.
- **Hint copy approved as written** (all four hints). No copy changes.

## Open questions / blockers

- **Missing first step.** The only start-up line fades after about four seconds (`MESSAGE_FADE_SECONDS`, `hud.gd`) and nothing tells a new player to open the map or build. Needs a persistent first-step prompt.
- **No confirmation of the right segment.** With the location already selected on entry, a new player gets no sign that they chose correctly.
- **Zoom wording.** "Scroll or pinch to zoom" should say that zooming in is how to reach segment mode.
- **"Got it" in segment mode.** Unclickable. Unverified suspicion: the full-screen map control, on its own canvas layer above the HUD, takes the click before the button sees it.
- **Enter to confirm.** Say it while the player is choosing tiles, not only once in a hint.
- **Cue coalescing at 4x** should count simulation time, or the window should shrink with speed. Decide which.
- Whether these become Linear items: file them with `/capture` after checking the closed list.
