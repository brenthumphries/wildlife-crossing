## Decisions made

- **B4: each Release asset is one archive per platform, Brent's call,
  2026-09-23.** Windows ships as `.zip` and Linux x86_64 as `.tar.gz`. Each
  holds the binary, its `.pck`, `LICENSE` and `THIRD-PARTY-NOTICES.md`, so the
  notices sit inside the published asset as
  [ADR 0017](../../docs/adr/0017-licensing.md) §Binaries must ship the notices
  requires, and the tarball keeps the Linux executable bit.
  `binary_format/embed_pck` stays `false`. CI builds the archives; on release
  day the Mac fetches them into `builds/` so the signed `SHA256SUMS.txt`
  covers all three platforms. Signing stays on the Mac per
  [signing-runbook](../../docs/signing-runbook.md) Part D. The runbook's B3
  `find` pattern changes to `*.dmg`, `*.zip`, `*.tar.gz`. macOS is unchanged by
  this decision and still goes to `.dmg` under C2.
- **Rejected: `embed_pck=true` with a bare binary.** One file per platform, but
  the licence files would live only in the in-game credits screen, which means
  amending ADR 0017 and root `CLAUDE.md`, and the Linux binary would need
  `chmod +x` after every download. It would also make the pack gate learn to
  read an embedded pack, new work with no test.
- **Decision separated from implementation.** The implementation is one
  supervised item for next week's plan, because it touches
  `game/export_presets.cfg`, `.github/workflows/ci.yml` and the website deploy
  allowlist, all forbidden paths. Per `plan.edit_midweek: never`,
  `week.json` is not edited here.

### Decisions made

- **C4: the tutorial camera stays at (13, 6), Brent's call, 2026-09-23.** At
  C10's 1280x720 and `CAMERA_ZOOM` 2.0 the camera shows 640x360 world px
  against a Bow Valley map (`game/data/world/sub_area_7.json`, 26 columns by
  12 rows) about 230 px tall, so all ten highway rows are on screen from any
  focus. (13, 6) frames the map evenly. Moving to rows 0 to 2, where 70 of 73
  baseline deaths happen per the 2026-08-10 measurement, would open a third to
  half of the screen above the map for no gain in what is visible. Framing is
  computed from `WorldRenderer.px_at_coord`, not observed. No code change.

  44% of the first screen empty above the map; (13, 1) also pushes rows 10 and
  11 (the alpine meadow) off screen.
