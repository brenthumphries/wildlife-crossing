- **C40.** Each season change writes the `autosave` slot using the quick-save fold; the quick-save slot is never written by it. Continue loads whichever slot has the later `saved_at_unix`. - **C42.** "Corridor N/12" counts the 12 sub-area milestones, with a capstone node that is dim until reached and gold after. A banner names each milestone and fades after 5 seconds. The chime is the existing `crossing_chime.wav` at 1.5x pitch, so no new audio. A save load updates the count without celebrating. 13 tests in `milestone_track_test.gd`.
- **C39.** `WorldData.apply_season` builds an effective terrain layer from the current season, never saved. Winter freezes every river tile (not hazardous). Spring floods the passable, non-hazard neighbours of a river tile (hazardous at the river's mortality rate). Summer and fall use the base terrain. Pathing, mortality and the renderer read `is_effective_hazard`; `Simulation` re-paths living agents on `season_changed` and keeps each agent's goal, so the RNG stream is untouched. `is_hazardous` and `is_impassable` never change with the season, so the connectivity graph, patch ids, population records and crossing placement stay put. The renderer draws frozen tiles pale and flooded tiles brown. 12 tests in `seasonal_terrain_test.gd`, including a span completed in each of the four seasons. A mutation check (removing the re-path call) made `test_season_change_invalidates_cached_paths` fail.
