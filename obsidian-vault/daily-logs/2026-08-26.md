## Decisions made

- **Merge PR #1 with a merge commit, not a squash.** Brent's call once the
  consequence was named. B2's acceptance is
  `git rev-list --count origin/main..HEAD` reaching 0, and a squash rewrites the
  branch into one commit that is not an ancestor of `HEAD`, so the count would
  stay at 10 after a successful merge. Merge commit or rebase are the only
  strategies under which that acceptance reads what it says.
- **Three commits, not one.** The eight uncommitted paths were three unrelated
  concerns, and one message covering build-review notes and a signing key
  explains neither.
- **The README carries the fingerprint, not the Windows SmartScreen warning.**
  Runbook C2 wants that warning in the v0.1.0 release note and beside the
  website download button. Those are C6 and B6.
