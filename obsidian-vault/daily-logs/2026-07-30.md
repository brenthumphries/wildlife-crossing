## Decisions made

- **`push-runbook.md` documents the full pipeline, not just git mechanics.**
  The commit/push steps are the easy part; the CI-watching and
  artifact-verification steps are what actually took iteration to get right
  this session (`gh` invocation syntax, `check_pck_contents.py`'s argument
  form, the zip-vs-bare-`.app` artifact-packaging difference), so those are
  the parts most worth having written down.
- **Commits stay grouped thematically, not one-per-day.** Continues the
  precedent set by the deleted B1 runbook and keeps `git log` reviewable per
  root `CLAUDE.md`'s Conventional Commits convention.

- **Span tiles are placed one click at a time, and completion requires an
  explicit confirm (Enter), not auto-complete on the first valid core.**
  Brent's call, weighed against click-drag placement and auto-complete
  respectively. Click-per-tile matches the PRD's "tiles each cell
  individually" wording with no drag-state to manage. Explicit confirm
  matches the existing `ConfirmPanel` Confirm/Cancel pattern already used
  elsewhere in the UI, and creates a clean moment to show a rejection message
  for an invalid attempt rather than the player wondering why nothing
  happened after a click.
- **Build mode hardcodes `crossing_type = "overpass"` for now, no type
  selector.** `infrastructure.json` marks overpass as the only
  `available_in_v1` type; underpass and corridor ship later. Adding a
  selector with one real option would be UI for a choice that doesn't exist
  yet — revisit when a second type lands.
- **The build-mode status label is its own small `Label`, not part of C1's
  HUD.** C1 is scoped to the crossing-success cue (roadmap Phase 1's
  "visual + audio placeholder cue"), a different concern from a live
  cost readout during placement. It's another ad-hoc code-instantiated
  `Control`, same pattern as `ConfirmPanel` and `ConnectivityOverlay` — this
  reproduces the "`BaseScreen` convention debt" the 07-28 build review
  already flagged rather than resolving it. C1's HUD is the next thing that
  will face this same choice; worth a call before then.
