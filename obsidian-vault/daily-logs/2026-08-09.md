## What I worked on

Licensing the repo for a public release, then building the credits screen that
the licensing turned out to require. One thread throughout: choose the licences,
write them, satisfy the obligations they create.

## What got done

- **Chose and wrote the licence set.** `LICENSE` (MIT, Copyright (c) 2026 Brent
  Humphries), `LICENSE-ASSETS` (CC0 1.0 with a header naming covered and
  excluded paths), `THIRD-PARTY-NOTICES.md`, and
  [ADR 0017](../../docs/adr/0017-licensing.md).
- **Found a standing licence breach.** Godot's export templates statically link
  the engine into every binary, Godot is MIT, and MIT requires its notice in all
  copies. Every binary this project has produced shipped without it. Nothing in
  any build review had flagged it.
- **CI now ships the notices.** A `Bundle license notices with each build` step
  in `.github/workflows/ci.yml` copies `LICENSE` and `THIRD-PARTY-NOTICES.md`
  into each `builds/<platform>/` before the upload step. Runs under `always()`
  and tolerates missing directories, so a failed preset cannot strip notices off
  the presets that worked.
- **Filled two empty `application/copyright` fields** in
  `game/export_presets.cfg` (Windows `preset.2`, macOS `preset.3`). Godot writes
  these into the Windows resource block and the macOS `Info.plist`.
- **Wrote `CONTRIBUTING.md`** with the Developer Certificate of Origin 1.1,
  verified byte-identical against developercertificate.org. Inbound equals
  outbound: MIT for code, CC0 for everything else, no CLA.
- **Built `CreditsScreen`** (`game/scripts/ui/credits_screen.gd`). Generates
  91,064 characters across 2,227 lines at runtime from
  `Engine.get_copyright_info()` and `Engine.get_license_info()`: 99 components
  with deduplicated copyright lines, then all 19 licence texts in full. Nothing
  hand-written, so an engine bump cannot leave it stale.
- **Verified the `Engine` API shapes against the pinned 4.6.3 binary** rather
  than assuming them. `copyright` is a `PackedStringArray` of holders without
  the "Copyright (c)" prefix, and `license` is an identifier such as `Expat`,
  not the licence text. A test pins that shape so a future bump fails in the
  suite instead of silently rendering an empty attributions list into a shipped
  binary.
- **Built the front end the screen needed.** `MainMenu` (Play, Credits, Quit,
  emitting intent only) and `TitleScreen`, which owns the scene change.
  `run/main_scene` is now `res://scenes/TitleScreen.tscn`; `Main.tscn` remains
  the playable root. `F1` opens the credits from inside play. Added
  `config/version="0.1.0"` to `project.godot`, which did not exist.
- **Kept the smoke gate intact through the boot-scene change.**
  `tools/smoke_boot.sh` now boots twice: bare, asserting `Title screen ready`,
  then with `-- --skip-menu`, asserting `Tutorial loaded` as before. Tested its
  logic against four synthetic logs, including the case that matters: a
  menu-only boot still fails the tutorial assertion.
- **Suite green at 20 scripts, 188 tests, 2,871 asserts.** 41 tests added across
  two new files (25 in `credits_screen_test.gd`, 16 in `main_menu_test.gd`), up
  from 18 scripts and 147 tests. Both boot paths run clean headless against the
  pinned binary, no `ERROR:` or `SCRIPT ERROR` in either.
- **Caught and corrected an invented attribution.** The first draft of
  `THIRD-PARTY-NOTICES.md` stated copyright holders for Courier Prime and
  Lobster Two. GUT's bundled `game/addons/gut/fonts/OFL.txt` carries only the
  Anonymous Pro line and documents neither of the others. The file now says so
  explicitly. `CLAUDE.md` gained a rule against reproducing any licence or
  copyright line from memory.
- **Deduplicated repeated copyright holders per component.** Godot's own data
  repeats them: Bullet lists the Godot contributors twice on 4.6.3. Two tests
  cover it, one asserting repeats collapse and one asserting genuinely distinct
  holders survive, since collapsing those would drop a required attribution.

## Decisions made

- **MIT for code and binaries, CC0 1.0 for everything else.** Brent's call,
  recorded in [ADR 0017](../../docs/adr/0017-licensing.md). GPL-3.0 was rejected
  on three grounds: it prevents closing a fork but not selling one, console SDKs
  are NDA'd and GPL-incompatible so it forecloses ports, and copyleft's
  enforcement mechanism is copyright, which AI-generated portions of this
  codebase may not carry. CC BY 4.0 was considered for assets and rejected in
  favour of CC0.
- **Trademark is the actual protection, not the licence.** Both licences
  deliberately permit forking and selling. What a fork may not do is call itself
  Wildlife Crossing. Stated in `LICENSE-ASSETS` (CC0 section 4(a) does not waive
  trademark), `README.md`, and `CONTRIBUTING.md`.
- **DCO, not a CLA.** A DCO attests origin. It does not grant relicensing
  rights, so the first merged outside contribution is the point of no return on
  the licensing model. Recorded as a consequence in ADR 0017 rather than left
  implicit.
- **The title screen boots and the smoke test skips past it.** Two alternatives
  were rejected. Overlaying the menu on a live tutorial would have made Play a
  lie and wasted a world load at boot. Repointing `SUCCESS_LINE` at the title
  screen would have gutted the gate: a build whose `data/*.json` never loaded
  still reaches a working menu, which is exactly the failure the script was
  written to catch (2026-07-28 build review).
- **The credits screen is the primary compliance mechanism, the loose files are
  the second copy.** Text rendered from inside the binary cannot be separated
  from it. The files remain for distributors and packagers who never launch the
  game.

  [push-runbook](../../docs/push-runbook.md).
- **The credits screen has never been seen in a windowed build.** Verified only
  by unit tests and headless boots. Nobody has looked at its layout, scrolling,
  or whether 91 KB of text is legible at `BODY_FONT_SIZE`. Folds into B1.
- **The boot-scene change is unverified against a real export.** Both boots pass
  against the project directory with the editor binary. Neither has run against
  an exported binary, which is what `smoke_boot.sh` actually takes. The CI smoke
  step now runs two boots, roughly doubling its runtime.
- **Nothing enforces the DCO sign-off.** Review only, no bot. A DCO check in
  `ci.yml` is worth adding before the repo is announced, since a missing trailer
  is far cheaper to fix before merge than after.
- **The macOS notice gap is narrowed, not closed.** The screen carries the
  notice inside the binary, but that preset exports a `.zip`, so `LICENSE` and
  `THIRD-PARTY-NOTICES.md` still land outside the `.app` bundle.
- **The menu version line reads `Godot Engine 4.6.3-stable (official)`.**
  `get_version_info()["string"]` includes the build type. Accurate, slightly
  noisy, untrimmed.
- **No `CONTRIBUTING.md` inbound-licensing story for third-party assets yet
  beyond a prohibition.** The file tells contributors not to vendor without a
  notice entry, but nothing checks it.
