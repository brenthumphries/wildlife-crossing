## Also this session: B6, v0.1.0 cut and published as a pre-release

This section supersedes the earlier "Next session" item 1 and the "Unclaimed changes" line above: the release note is finalised and merged, and B6's build, signing, checksum, tag and Release are done.

### What I worked on

Cut v0.1.0 per `docs/signing-runbook.md` A6, A7, B3 and B4: cleared `builds/`, exported the three platforms, found the notices missing from the signed `.dmg`, rebuilt it with them, checksummed from a flat folder, signed the manifest, tagged and published.

### What got done

- **Release note finalised and merged.** [PR #49](https://github.com/brenthumphries/wildlife-crossing/pull/49) (`4818895`) added `docs/release-notes/v0.1.0.md` with `date: 2026-10-12`, `status: active`. Its facts were checked against the repo first: eight species, twelve sub-areas, the key bindings, and the GPG fingerprint against `wildlife-crossing-signing-key.asc`. [PR #50](https://github.com/brenthumphries/wildlife-crossing/pull/50) (`d023ef7`) then added the `LICENSE` and `THIRD-PARTY-NOTICES.md` row, said Windows and Linux share one `wildlife-crossing.pck`, and made the signing-key link absolute.
- **Exports run from `game/` with Godot 4.6.3.** `builds/` was cleared first, and its subfolders had to be recreated because Godot does not create the output folder. macOS, Windows x86_64 and Linux x86_64 all exported with no errors. `game/export_presets.cfg` showed no diff afterwards.
- **The first Godot-made `.dmg` had no notices inside.** It held only `Wildlife Crossing.app`, against ADR 0018's Decision, C2's acceptance and the root `CLAUDE.md`. It had been notarized (request `0c79800e-452b-487f-a866-8c3ee085d7ab`), stapled, and accepted by `spctl`, but was not the file to ship.
- **Rebuilt the `.dmg` with the notices inside** (Option 1): the app copied out with `ditto` (`codesign --verify --deep --strict` valid), `LICENSE` and `THIRD-PARTY-NOTICES.md` added, `hdiutil create`, signed with the Developer ID Application identity, notarized (submission `d88402c2-2cf0-402c-9182-e1600af65f4e`, status `Accepted`), stapled, validated. `spctl -a -vvv -t install` reports `accepted`, `source=Notarized Developer ID`, `origin=Developer ID Application: Brent Humphries (TSJJSCHY4Z)`. The original is kept outside the repo at `~/wc-dmg-work/godot-original.dmg`.
- **C2's owed check, done on the real signed `.dmg`.** `tools/check_pck_contents.py` on the rebuilt image reports OK: 105 files, 20 data files, 2 runtime assets, no `addons/gut` or tests paths. A read-only mount lists `LICENSE`, `THIRD-PARTY-NOTICES.md` and `Wildlife Crossing.app`; the notices are byte-identical to the repo's, the app signature is valid, and `CFBundleShortVersionString` is `0.1.0`. The same gate passes on the Windows and Linux packs, which are byte-identical to each other (`cmp`).
- **Checksum and signature.** `SHA256SUMS.txt` was built in a flat staging folder (`~/wc-release-v0.1.0/`) listing six files: the `.dmg`, `.exe`, `.pck`, Linux binary, `LICENSE`, `THIRD-PARTY-NOTICES.md`. `gpg --verify` reports a good signature from `7F68 A7E0 6349 DA13 6226 F04E 2D5F 1ED6 EFFC 08FD`, and `shasum -a 256 -c` reports OK on all six. The first `gpg` attempt was a dismissed passphrase prompt; the retry signed.
- **Tagged and published.** Annotated tag `v0.1.0` points at `d023ef7` and is on `origin`. The GitHub Release was published on 2026-10-12 (16:26 UTC) as a **pre-release**, with eight assets: the six files above plus `SHA256SUMS.txt` and `SHA256SUMS.txt.asc`. Their sizes match the local staging files byte for byte (`.dmg` 71,462,465; `.exe` 104,519,168; `.pck` 1,588,060; Linux binary 71,075,864). URL: https://github.com/brenthumphries/wildlife-crossing/releases/tag/v0.1.0
- **Cleanup.** Local `docs/release-note-*` branches were merged and deleted.
