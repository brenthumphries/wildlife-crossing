Walked B1b in full (`docs/signing-runbook.md` A2-A4), reviewed and fixed Brent's own hand-edit of `game/export_presets.cfg` for C1, routed C7 rather than running it (Mac-only, not Claude Code's to touch even with shell access here), resolved a scope question on C2, and landed C1 and C2 as one pull request.

### What got done

- **B1b: A2 and A4 confirmed done.** Brent has the Developer ID Application certificate and the App Store Connect API key. Since both are gated on Apple's enrolment approval per the 2026-08-27 log, this is indirect but solid evidence the enrolment cleared sometime between 2026-09-23 (last recorded as "still pending") and today. A3 (Xcode license accept) was not independently confirmed this session. I gave Brent the two commands but have no confirmation either ran.
- **C1's hand-edit had two real errors, both from misreading `security find-identity`'s output format** (`<SHA-1 hash> "<identity string>"` on one line). `codesign/apple_team_id` had been set to the hash instead of the parenthesized Team ID; `codesign/identity` carried the hash prepended to the identity string plus unescaped nested double-quotes that would not have parsed as valid `.cfg` syntax. Both corrected.
- **`game/project.godot` briefly lost every one of its comments** (the ADR 0012 pin note, the title-screen boot-flow explanation, C10's full `[display]`-section rationale, the ETC2 ASTC export requirement), discovered via `git status` before anything was staged, most likely from Godot resaving the file when the export preset was opened in the editor for A5. Reverted with `git checkout -- game/project.godot` before it could land in any commit. Not fixed at the root; will very likely recur the next time the project opens in the editor.
- **C2 scoped down after checking a real constraint, not assumed.** `signing-runbook.md` A6 states DMG export only works from macOS; CI's `export` job runs on `ubuntu-latest`, and its command passes an explicit `.zip` output path that overrides whatever the preset's own `export_path` says, so CI cannot produce a `.dmg` regardless of this change. Raised whether to add a `macos-latest` CI runner for real signing/notarization (would need certificate and API-key secrets in GitHub Actions, on a repository that's been public since 2026-08-29); Brent declined, citing A6 directly.
- **C1 and C2 landed together as [PR #37](https://github.com/brenthumphries/wildlife-crossing/pull/37)**, two commits (`ef2b8b0`, `cf1abb8`): the signing fields, and `export_path` → `.dmg` for the macOS preset. Not merged yet, so neither item is closed in the tracking sense used elsewhere in this log (closure = merged); no review-note amendment written for either, owed once the PR merges.
- **A stale `ci.yml` comment corrected in the same PR.** It described the in-game credits screen as an unbuilt "durable fix" for the licence-notice gap; ADR 0017's 2026-08-09 amendment shows `CreditsScreen` already renders every attribution at runtime. Rewritten to say so and to explain plainly why CI's own loose-notice copies land beside the `.app`, not inside it (CI's `.zip`, not the release `.dmg`).
- **GUT suite run locally for the first time since C7**: 28 scripts / 310 tests / 6,378 asserts, all passing, matching `docs/plan/facts.json`'s stated scripts exactly. Nothing dropped.
